# ClassConnect

A digital tutoring platform designed to connect students with university student educators through a structured and secure learning environment.

## Overview

ClassConnect is a web-based tutoring platform developed as a senior project at Ankara Yıldırım Beyazıt University, Department of Management Information Systems.

The platform aims to simplify the tutoring process by providing students with a way to discover educators, manage appointments, and participate in scheduled lessons.

## Features

- Student and teacher registration and login
- Google and Microsoft authentication
- Student and teacher profile management
- Teacher and lesson discovery
- Appointment scheduling and management
- Pending, confirmed, and cancelled appointment statuses
- Real-time lesson session management
- Password reset functionality
- Role-based student and teacher workflows

## System Architecture

ClassConnect follows a client-server architecture.

The frontend communicates with a Node.js and Express.js backend through API endpoints. MySQL is used as the relational database, while Socket.IO provides real-time communication for live lesson sessions.
